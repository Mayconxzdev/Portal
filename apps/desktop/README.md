# Portal Vesper - Desktop Application

Este diretório está reservado para o invólucro (wrapper) desktop nativo do Portal Vesper utilizando a tecnologia **Tauri**.

## 📅 Planejamento Futuro
O empacotamento desktop será iniciado após a conclusão e consolidação da base web e de APIs do portal. Consulte o documento [TAURI_SETUP_LATER.md](TAURI_SETUP_LATER.md) para saber mais sobre as decisões e os requisitos para habilitar o Tauri futuramente.
