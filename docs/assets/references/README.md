# Referências Visuais do Portal Vesper

Estas imagens são referências conceituais aprovadas para tema claro.

Elas orientam hierarquia, densidade, layout e clareza. Não são screenshots de produção, não comprovam funcionalidades e podem conter dados ilustrativos.

Ao implementar:

- usar dados e permissões reais;
- manter o shell global do Portal;
- adaptar o layout ao módulo;
- validar tema escuro com a mesma qualidade;
- não copiar nomes, valores ou métricas fictícias;
- não criar funcionalidade fake apenas porque aparece na imagem.

Consulte `../../VISUAL_REFERENCE_GUIDE.md` e o documento correspondente em `../../modules/`.
