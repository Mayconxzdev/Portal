# Evidências visuais do portfólio

As imagens desta pasta foram selecionadas a partir da galeria visual do projeto e otimizadas para carregamento no GitHub.

- não são capturas de uma empresa em produção;
- usam dados sintéticos e fluxos representativos;
- não contêm uploads, bancos, credenciais ou arquivos operacionais;
- servem para demonstrar hierarquia visual, densidade de informação e jornadas do produto.

Os arquivos originais de referência permanecem em [`docs/assets/references/`](../assets/references/), também em formato WebP.
